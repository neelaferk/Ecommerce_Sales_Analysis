# Ecommerce_Sales_Analysis
E-commerce sales analysis using Excel dashboard
## 📊 Project Overview
 -This project presents an interactive E-Commerce Sales Dashboard created using Microsoft Excel. The dashboard analyzes sales performance, order trends, product categories, regions, and   -customer payment methods.

 -The goal of this project is to transform raw sales data into meaningful business insights through Excel PivotTables, PivotCharts, KPIs, and interactive dashboard visualizations.
## 🎯 Objectives
* Analyze overall sales performance.
* Identify sales performance across different product categories.
* Analyze sales by region.
* Understand quantity sold by payment type.
* Track total orders and total quantity.
* Calculate average sales.
* Create an interactive and visually appealing Excel dashboard.
* Present business insights in an easy-to-understand format.
## 🛠️ Tools & Technologies
* Microsoft Excel
* PivotTables
* PivotCharts
* Excel Charts
* Dashboard Design
* Data Cleaning & Transformation
* Data Analysis
## 📌 Key KPIs
The dashboard includes the following key performance indicators:

* Total Sales
* Total Quantity
* Total Orders
* Average Sales
These KPIs provide a quick overview of the overall business performance.
